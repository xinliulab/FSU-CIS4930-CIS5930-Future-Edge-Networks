# Canvas homepage version

This folder contains a Canvas-friendly version of the course homepage.

## Files

- `home.html`: paste this into a Canvas Page using the HTML/source editor, then click **Save & Publish**.
- `materials-linked-from-github.md`: checklist of course files that `home.html` links from GitHub Pages.

Current status: `home.html` shows the full Fall 2026 calendar. The first four class meetings include topics; later class meetings are intentionally left blank while the rest of the course plan is being updated.

When updating the course schedule, update both:

- `../index.html` for the GitHub course homepage.
- `home.html` for the Canvas copy/paste version.

LaTeX-generated PDFs are linked directly from their source folders. After editing and compiling LaTeX, the homepage links use the newly generated PDFs without a separate copy step.

Full draft backups are stored in:

- `../archive/index-full-schedule-draft-2026.html`
- `../archive/canvas-home-full-schedule-draft-2026.html`

## Recommended materials strategy

Use GitHub as the source folder for public course materials, and use Canvas as the course hub.

In practice:

- Keep slides, PDFs, and public readings in this GitHub repository.
- Paste `canvas/home.html` into the Canvas page.
- The Canvas page links to course files with absolute GitHub Pages URLs, so Canvas does not need to preserve the repository folder structure.
- Use Canvas Files only for materials that should be private to enrolled students or that FSU requires to stay inside Canvas.

This avoids uploading the same slides twice. When a lecture file is updated and compiled in GitHub, the Canvas homepage link keeps working without editing Canvas.

## If Canvas-only files are required

Create a Canvas Files folder such as:

```text
Future Edge Networks / 2026 Fall / public-materials
```

Upload the PDFs and slides there, then replace the GitHub links in `home.html` with Canvas file links after upload. This is more private, but more work to maintain because Canvas file links are generated by Canvas and cannot be predicted from the repository path.
