\subsection*{Computer Accounts}

\begin{outline}
  \1 \textbf{GitHub Account:} You will need a GitHub account to access course assignments and use GitHub Codespaces.
  \1 \textbf{GitHub Student Developer Pack:} It is strongly recommended to apply for the 
     \href{https://education.github.com/pack}{GitHub Student Developer Pack} to access free credits for Codespaces and other developer tools.
  \1 \textbf{FSU Email:} You will need a \texttt{my.fsu.edu} account for receiving class emails. For more information, visit the
     \href{https://servicecenter.fsu.edu/s/article/Email-Account-Management-Information2}{FSU email account management page}.
\end{outline}
