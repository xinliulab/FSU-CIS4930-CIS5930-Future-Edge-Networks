\subsection*{Course Objectives} 

\begin{outline}
  \1 \textbf{Fundamental Goal: Applying AI/ML to 5G and Beyond}
    \2 \textbf{AI/ML for Wireless Networks:} Understand how modern machine learning, especially deep learning, can be used to improve the design and operation of 5G and beyond wireless systems.
    \2 \textbf{System-Level Thinking:} Connect networking principles with ML pipeline design, focusing on how learning components interact with real network constraints.

  \1 \textbf{Core Focus: 5G/ORAN and Hybrid Routing Systems}
    \2 \textbf{5G Architecture and ORAN:} Learn the overall 5G network architecture with an emphasis on the Open Radio Access Network (ORAN), its key interfaces, and deployment considerations.
    \2 \textbf{Model Routing in Edge Environments:} Design mechanisms to select, place, and invoke ML models dynamically across the network, balancing latency, accuracy, and resource constraints.
    \2 \textbf{Hybrid Routing Design:} Study how model routing and network routing interact, and learn to build integrated systems that jointly optimize both.

  \1 \textbf{Key Topics and Emphasis on Edge-Side Challenges}
    \2 \textbf{Edge Resource Constraints:} Analyze compute, memory, energy, and bandwidth limitations at the edge, and their implications for real-time ML inference and control.
    \2 \textbf{Wireless Fundamentals for Edge Intelligence:} Cover essential concepts such as OFDM and resource allocation, focusing on how they shape edge-side ML performance.
    \2 \textbf{Selective Coverage of the 5G Core:} Briefly introduce core-network concepts (e.g., slicing strategies) to provide context, while keeping the primary emphasis on edge-side challenges.
\end{outline}
