One rule, four times

The node names look like unrelated trivia until you notice that every architectural change since 1991 cuts along the same seam.

2G
Base station→ BTS holds the radio  +  BSC decides which channel
2001
MSC→ MSC Server decides  +  Media Gateway carries the voice
4G
Packet core→ MME decides  +  S-GW / P-GW carry the packets
5G
Control plane→ AMF for access and mobility  +  SMF for sessions
5G
gNodeB→ RU on the tower  +  DU in the cabinet  +  CU in a data centre

Each split separates what decides from what carries. Learn that seam and the acronyms stop being a vocabulary test.

Node and message names follow 3GPP terminology for each generation. Simplified for teaching: paging, retransmissions, roaming interfaces and most optional steps are left out.
