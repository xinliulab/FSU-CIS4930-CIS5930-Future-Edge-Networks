# Class 23 quiz: Edge AI Agents, From Perception to Action

Questions only. Answer from the slides and the spoken notes alone.
The expected answers live in `quiz-answers.md`; the student agent must never open that file.

1. In one or two sentences, what is the difference between a chatbot and an agent?

2. Name the steps of the agent loop. For the dinner-booking example, say what happens at each step.

3. A thermostat counts as an agent. Why? And what is new about today's agents compared with it?

4. In the short loop program, which line is "the model"? What is everything else called, and what does it do?

5. Name the four eras of agents and one thing that changed in each.

6. The time-horizon chart: what exactly does it measure, and roughly how did it change from 2023 to 2026? Give one caveat.

7. Pick three research areas from "the map" and say which part of the loop each one improves.

8. Give the three ways an agent can act on a phone app, with one advantage and one drawback of each.

9. In the latency budget of one loop step, which part dominates when the model runs in the cloud, and why does the number of steps matter so much? What changes when the model runs on the phone?

10. Why would a robot use two loops at different speeds? Give the rough rates of each.

11. Give one reason an agent should sense less, and one way to do it.

12. Which kinds of actions should an agent check before running them? Name two ways to check.

13. What is the "lethal trifecta", how does a prompt-injection attack use it, and how can running parts of the agent on the device help?

14. If each step succeeds 99% of the time, about how often does a 100-step task succeed? What can raise that number?

15. Where are most agents on the autonomy ladder in 2026, and what holds them back from going higher?
